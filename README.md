# Description :

This project is a password security testing tool designed for educational purposes. It demonstrates how weak passwords can be vulnerable to common attack methods such as brute force or dictionary-based attempts. The goal is to help users understand the importance of strong password practices and improve system security.

⚠️ This tool is intended only for ethical use, such as testing your own accounts or systems with permission.


# Features :

 Password Strength Testing
Evaluates how secure a password is based on length and complexity.
 Dictionary Attack Simulation
Attempts passwords using a predefined list of common words.
 Brute Force Demonstration
Shows how automated attempts can guess weak passwords over time.
 Time Estimation
Provides an estimate of how long it may take to crack a password.
 Simple User Interface
Easy-to-use interface for testing and learning.

# Why it matters :
In today’s digital world, passwords protect everything—from social media accounts to banking information. However, many people still use weak or predictable passwords.

This project helps to:

Raise awareness about cybersecurity risks
Encourage the use of strong, unique passwords
Demonstrate how attackers exploit weak security
Promote safer online habits

By understanding how password attacks work, users can better protect themselves and others from unauthorized access.
